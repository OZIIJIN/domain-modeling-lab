# SpaceRoom — 원본 기획서

## 배경

SpaceRoom은 여러 공유 오피스 지점을 운영하는 기업을 위한 회의실 예약 서비스다. 기존에는 직원이 관리 담당자에게 문의하고 스프레드시트로 예약을 관리해 중복 예약 문제가 발생했다.

## 사용자

- 입주사 직원: 근무 지점 회의실 조회·검색, 본인 예약 생성·조회·변경·취소
- 지점 관리자: 담당 지점 회의실 등록·수정·삭제, 예약 현황 확인, 사용 제한과 해제

## 핵심 요구사항

### 회의실
회의실은 이름, 수용 인원, 위치, 이용 가능한 시설 정보를 포함한다. 관리자는 등록·수정·삭제한다.

### 검색
직원은 날짜, 시간대, 최소 수용 인원으로 예약 가능한 회의실을 검색한다. 검색 결과에는 이름, 위치, 수용 인원, 시설 정보가 표시된다.

### 예약
- 직원은 회의실과 사용 시작·종료 시각을 선택한다.
- 최소 30분, 최대 4시간 예약 가능.
- **예약 시작 시각**은 30분 단위로 지정.
- 동일 회의실에 대해 이용 시간이 겹치는 예약 불가.
- 직원은 본인 예약 조회 가능.
- 완료 후 예약 결과 표시.

### 변경·취소
- 직원은 본인 예약의 사용 시간 또는 회의실을 변경할 수 있다.
- 사용 시작 1시간 전까지 취소 가능.
- 취소된 예약 시간대는 다른 직원이 다시 예약 가능.

### 사용 제한
- 관리자는 점검·보수 때문에 특정 회의실의 특정 시간대를 제한 가능.
- 제한 시간대에는 신규 예약 불가.
- 제한 해제 가능.

## 주요 예외

- **A 중복 예약**: 이미 예약된 회의실·시간대 요청은 거절.
- **B 변경 실패**: 새로운 시간대가 중복 예약이면 기존 예약을 유지.
- **C 회의실 삭제**: 미래 예약이 남아 있을 때의 처리 정책은 미결정.
- **D 시설 점검**: 제한할 시간대에 기존 예약이 있으면 충돌을 알려야 하나 후속 처리 방식은 미결정.

미결정 정책은 임의로 확정하지 않는다.
