# Domain Modeling Lab

자연어 요구사항에서 도메인 규칙을 발굴하고, 최초 답변과 피드백, 수정한 판단을 기록하는 훈련 저장소입니다.

## 진행 현황

- [001 SpaceRoom — 공유 오피스 회의실 예약](cases/001-spaceroom/README.md): STEP 1·2 완료 / STEP 3 대기

## 훈련 단계

1. 업무 규칙 추출
2. 엔티티 후보 도출
3. 책임과 생명주기
4. 관계와 카디널리티
5. 속성과 제약조건
6. 시나리오 검증

각 사례는 최초 분석 → 반례·피드백 → 개선한 판단 → 미결정 정책의 흐름으로 정리합니다.
